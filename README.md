# Location Pitch Builder | HAHA Vending

智能零售柜点位评估、点位方收益测算、商业提案生成与合规文件中心。

## 最新版本更新亮点

1. **点位评估（Location Assessment）**：
   - “重置评分”和“保存评估”按钮靠右放置在“当前权重为原型默认值”同一行右侧（即 `STEP 01` 正上方），且“点位基本信息”与右侧 `LOCATION SCORE` 外框顶部保持平齐。
   - 移除右侧 `LOCATION SCORE` 卡片内的冗余下一步按钮，统一使用左栏底部的“下一步：点位方收益测算 →”按钮，点击后自动滚回新页面最顶端。
2. **点位方收益测算（Site Partner Earnings）**：
   - 左侧导航栏、面包屑与页面标题在中英文切换下均严格保持为“点位方收益测算 / Site Partner Earnings”。
   - “测算说明”明细内容拆分为 4 段结构化条目（1. 点位方月度收益、2. 运营商月净收益、3. 周期累计与回本、4. 测算口径说明），清晰易读。
3. **商业提案生成（Business Proposal）**：
   - 机型图片高度放大至 `285px`，并针对 `Ultra 1200` 的 `16:9` 偏左画布做专门的居中裁切对齐（`object-fit: cover; object-position: 18% 50%`），使所有机型图片均饱满居中。
   - 自动清理浏览器本地缓存（`localStorage`）中旧版的“收益测算参考：预计月销售额…”文本，确保左侧“其他合作说明（场地免责与试运营保障）”与右侧实时预览均展示零场地改造成本、即插即用、$2M 商业责任险与 90 天试运营保障条款。
