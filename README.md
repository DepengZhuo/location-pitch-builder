# Location Pitch Builder | HAHA Vending

智能零售柜点位评估、点位方收益测算、商业提案生成与合规文件中心。

## 最新版本更新亮点（v4）

1. **点位评估模块全新升级（参考 `location-assessment-prototype` 交互逻辑）**：
   - **`2. 点位条件评估 / 2. Rate the Location`**：5 项核心指标（人流量与稳定性 25 分、目标客群匹配度 25 分、消费需求与便利性 20 分、摆放位置可见度与动线 15 分、运营与补货可行性 15 分），每项支持 **强 (Strong, 100%) / 一般 (Average, 50%) / 弱 (Weak, 0%) / 待确认 (Not sure, 暂不计分)** 四档直观评估。
   - **`3. 部署准备度核查 / 3. Deployment Readiness`**：独立核查物业审批许可、空间与电源条件、补货与维保通行、物业对接人与合作条款 4 项安装前置条件。
   - **`评估总结分析 / Assessment Summary`**：完成全部 5 项有效评分后自动展开优势亮点、待关注项与针对性下一步行动建议。
   - **`LOCATION SCORE` 悬浮侧边栏与计分规则说明**：实时显示完成进度、5 项评分拆解进度条、部署准备状态汇总及计分规则说明卡片（保持全站统一的黑白灰商务视觉风格，移除冗余的 Reset / Print 按钮）。
2. **全模块中英文无缝切换与数据联动**：
   - 所有新增评估项、准备度下拉框、动态总结与计分规则均支持 **中文 / EN** 100% 同步切换，并与工作台统计、“我的项目”列表及本地存储自动联动。
